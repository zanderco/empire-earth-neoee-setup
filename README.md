# Empire Earth (NeoEE) family LAN setup

Scripts and guides for setting up Empire Earth (NeoEE community edition) under
Wine so the family can play LAN matches. Each player uses their own GOG
purchase of Empire Earth Gold Edition; no game files are in this repository.

## Where to start

| Your situation | Read this |
|---|---|
| A person installing on a Mac for the first time | `READ-ME-FIRST.md` |
| An AI assistant installing on a Mac for the first time | `START-HERE-AGENT.md` |
| An AI assistant updating a Mac that already has the game (Nov 25, 2026 update: screen fit and zoom) | `UPDATE-AGENT.md` |
| An AI assistant installing on Linux | `LINUX-AGENT-BRIEF.md` |
| Testing two computers before game night | `TWO-MAC-TEST.md` |

## One file is not here

`NeoEE_Setup.exe` (645,063,720 bytes) is too large for GitHub. Download it in a
web browser from https://empireearth.eu/download/neo/ into your Downloads
folder. The setup script looks for it there and checks its checksum before
using it.

## What has been tested

Read the status notes in `READ-ME-FIRST.md` before relying on any of this. In
short: the Mac recipe has worked on two Macs and the Linux one on one machine.
The screen fit and zoom update of Nov 25, 2026 has been played on the Linux
machine only; it has not been run on a Mac yet.
